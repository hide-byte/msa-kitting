# 新 PC キッティング手順（Dell・Windows 11 Pro）

新しいパソコンを会社で使える状態にする手順です。**1 台あたり 40〜70 分**。2 台同時に進めて構いません。

画面イメージ付きの版: **https://hide-byte.github.io/msa-kitting/** （スマホでも PC でも開けます。サインイン不要）。この文書は同じ内容の文字版です。

---

## 0. 用意するもの

| もの | どこから |
|---|---|
| 社内 Wi-Fi の名前（SSID）とパスワード | 岡島さん |
| 端末番号（例: `MSA-PC-043`） | hide さんから受け取る（台帳の次の番号・2 台分） |
| 利用者の名前 | この PC を使う人 |
| ローカルアカウント名とパスワード | 岡島さんの規約どおり |
| この手順を見るためのスマホ or 別 PC | 手元 |

---

## 1. 電源を入れて初期セットアップ（Windows の最初の画面）

箱から出して電源を入れると、Windows の初期設定画面（OOBE）が始まります。画面の順に進めます。

1. **国または地域**: 日本 → はい
2. **キーボード レイアウト**: Microsoft IME → はい → 「2 つ目のレイアウトを追加しますか？」は **スキップ**
3. **ネットワークに接続**: 社内 Wi-Fi を選んでパスワードを入力 → 次へ（更新の確認で数分待つことがあります）
4. **ライセンス契約** → 同意
5. **デバイスに名前を付けましょう**: 端末番号（例 `MSA-PC-043`）を入力 → 次へ（再起動がかかります）
6. **このデバイスをどのように設定しますか？** → **「職場または学校用に設定する」** を選ぶ → 次へ
7. サインイン画面が出たら、入力欄の下にある小さな文字 **「代わりにドメインに参加する」** をクリック
8. **このデバイスを使うのはだれですか？** → ローカルアカウント名 → 次へ → パスワード → 確認 → 秘密の質問を 3 つ
9. **プライバシー設定**: すべて「いいえ」にして → 同意
10. デスクトップ（壁紙）が表示されたら完了。**Microsoft アカウントは作りません。**

### 「代わりにドメインに参加する」が画面に無いとき

新しい Windows のビルドでは出ないことがあります。順に試してください。

- **方法 A**: 手順 6 の画面で、キーボードの **Shift + F10** を同時押し → 黒い画面が出る → `start ms-cxh:localonly` と打って Enter → ローカルアカウントを作る画面が出るので手順 8 と同じように入力
- **方法 B**: 方法 A が効かなければ、いったん電源を長押しで切り、Wi-Fi に**つながない**で手順 3 まで進め、「インターネットに接続していません」→「制限された設定で続行」を選ぶ → ローカルアカウントを作る
- **方法 C**: それでも無理なら、hide さんの指示で Microsoft アカウントで進め、後から「設定 → アカウント → ユーザーの情報 → ローカル アカウントでのサインインに切り替える」で戻します

---

## 2. ターミナル（管理者）を開く

1. キーボードの **Win キー**（田のマーク）を押しながら **X** を押す
2. 出てきたメニューから **「ターミナル (管理者)」** をクリック
3. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **はい**

黒い画面（ターミナル）が開きます。先頭に `PS C:\Users\...>` と出ていれば OK です。

---

## 3. コマンドを貼り付けて Enter

下の 1 行をすべてコピーして、黒い画面の中で **右クリック**（貼り付けになります）→ **Enter**。

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/hide-byte/msa-kitting/main/bootstrap.ps1 | iex
```

「MSA キッティング ブートストラップ」という水色の帯が出れば開始しています。

---

## 4. 聞かれたら入力

アプリのインストール（5〜30 分）が終わると、次の項目を聞かれます。

| 聞かれること | 入力例 | メモ |
|---|---|---|
| 端末番号 | `MSA-PC-043` | 台帳で採番した番号 |
| 利用者名 | `三浦 英直` | この PC を使う人 |
| 部署 | `営業部` | 分からなければ Enter だけ |
| 設置場所 | `本社2F` | 分からなければ Enter だけ |

入力して Enter で次へ進みます。

## 5. 完了画面を確認

最後に **緑の枠で「✅ キッティング Phase 1 完了」** と出れば成功です。その下に「残りの手作業」が 3 つ表示されます。

```
════════════════════════════════════════════
  ✅ キッティング Phase 1 完了
════════════════════════════════════════════
```

## 6. 残りの手作業（3 つ・各 5 分）

1. **Dell Command | Update**: スタートメニューで「Dell Command」と検索して開く → 「確認」→ 見つかった更新を **すべてインストール**（ドライバと BIOS）。再起動を求められたら再起動
2. **McAfee の削除**（画面に「McAfee が残っています」と出た場合だけ）: 設定 → アプリ → インストールされているアプリ → 「McAfee」の右の **…** → アンインストール
3. **Windows Update**: 設定 → Windows Update → **更新プログラムのチェック** → すべて入れて再起動。「更新プログラムはありません」になるまで 2〜3 回繰り返す

---

## 7. 台帳に記録

`C:\msa-kitting-logs\assets-日付.csv` に端末情報（シリアル番号・型番・OS など）が保存されています。メモ帳で開いて内容を PC 台帳（Excel / スプレッドシート）にコピーしてください。

このあとのメール・VPN・共有フォルダ・プリンタは hide さん or 岡島さんが設定します。hide さんに Chatwork で「キッティング完了しました」と連絡してください。

---

## ❌ 失敗したとき

赤い枠で **「キッティング途中で失敗」** と出たら、ウィンドウを閉じずに次の手順を。

1. エクスプローラで `C:\msa-kitting-logs` を開く
2. 一番新しい `setup-日付.log` を **メモ帳** で開く
3. `Ctrl + A` → `Ctrl + C` で全文コピー
4. **hide さんへの Chatwork** に次のように貼って送信

```
MSA キッティングで失敗しました。ログ全文を貼ります：

[ここに Ctrl + V]
```

5. hide さんから次のコマンドが返ってくるので、ターミナルに貼って Enter

同じコマンドをもう一度実行しても大丈夫です（終わった作業は自動で飛ばします）。

## よくある質問

**Q. 途中で再起動した**
A. 正常です。再起動後にもう一度「2. ターミナル（管理者）を開く」から同じコマンドを貼ってください。

**Q. 「管理者権限が必要です」と赤く出た**
A. Win + X → 「ターミナル (管理者)」で開き直してください。「(管理者)」が付いていないターミナルでは動きません。

**Q. 「ダウンロードに失敗」と出た**
A. Wi-Fi を確認してください。Edge で https://github.com が開けるか見てみてください。

**Q. 黒い画面に日本語が「????」や記号で表示される**
A. 動作には影響ありません。hide さんに「文字化けしています」と伝えてください（スクリプト側の修正対象です）。

**Q. どのくらい待てばいい？**
A. アプリのインストールで 5〜30 分。Acrobat Reader が 700MB 以上あるので回線によっては時間がかかります。30 分以上画面が変わらなければ hide さんに相談してください。
