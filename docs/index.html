1電源を入れて初期設定15〜20 分

箱から出して電源を入れると Windows の初期設定が始まります。ほとんどは「次へ」を押すだけです。大事なのは 6〜8 番。ここで Microsoft アカウントを作らずに会社用のローカルアカウントを作ります。

  1. 国または地域: 日本 → はい
  2. キーボード レイアウト: Microsoft IME → はい。「2 つ目のレイアウトを追加しますか？」は スキップ
  3. ネットワークに接続: 社内 Wi-Fi を選んでパスワード → 次へ（更新の確認で数分待つことがあります）
  4. ライセンス契約 → 同意
  5. デバイスに名前を付けましょう: 端末番号（例 MSA-PC-043）→ 次へ（一度再起動します）
  6. このデバイスをどのように設定しますか？ → 「職場または学校用に設定する」 → 次へ ↓画面 A
  7. サインイン画面の入力欄の下にある小さい文字 「代わりにドメインに参加する」 をクリック ↓画面 B
  8. このデバイスを使うのはだれですか？ → ローカルアカウント名 → パスワード → 秘密の質問 3 つ ↓画面 C
  9. プライバシー設定: すべて「いいえ」→ 同意
  10. 壁紙（デスクトップ）が出たら完了

「代わりにドメインに参加する」が画面 B に無いとき

新しい Windows では消えていることがあります。上から順に試してください。

方法 A（まずこれ）: 画面 A のところでキーボードの Shift + F10 を同時に押すと黒い画面が出ます。そこに start ms-cxh:localonly と打って Enter。画面 C と同じ「だれが使いますか」が出るので、同じように入力します。

C:\Windows\System32> start ms-cxh:localonly
Shift + F10 で出る黒い画面。半角で入力して Enter

方法 B: 方法 A で何も起きなければ、電源ボタン長押しで切り、Wi-Fi につながずに手順 3 まで進め、「インターネットに接続していません」→「制限された設定で続行」を選ぶとローカルアカウントを作れます。

方法 C: どうしても無理なら hide さんに連絡。hide さんの Microsoft アカウントで進め、あとで「設定 → アカウント → ユーザーの情報 → ローカル アカウントでのサインインに切り替える」で戻します。

3コマンドを貼り付けて Enter1 分 + 待ち 5〜30 分

下の 1 行をコピーして、黒い画面の中で 右クリック（それだけで貼り付けになります）→ Enter。

Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/hide-byte/msa-kitting/main/bootstrap.ps1 | iex

おすすめ: 新しい PC の Edge で hide-byte.github.io/msa-kitting を開くと、このページの「コピー」ボタンがそのまま使えます。スマホだけで進める場合は、文字を見ながら打ち込んでください（半角・大文字小文字そのまま）。

6仕上げの手作業3 つ・各 5 分

① Dell Command | Update

スタートメニューで「Dell Command」と検索して開く → 確認 → 見つかった更新をすべてインストール。再起動を求められたら再起動。

② McAfee の削除

画面 H に「McAfee が残っています」と出ていた場合だけ。設定 → アプリ → インストールされているアプリ → McAfee の右の … → アンインストール ↓画面 I

③ Windows Update

設定 → Windows Update → 更新プログラムのチェック → すべて入れて再起動。「最新の状態です」になるまで 2〜3 回繰り返す。

7台帳に記録して連絡5 分

端末情報（シリアル番号・型番・OS など）が C:\msa-kitting-logs\assets-日付.csv に保存されています。メモ帳で開いて、内容を PC 台帳（Excel / スプレッドシート）にコピーしてください。

そのあと hide さんに Chatwork で 「キッティング完了しました」 と連絡。メール・VPN・共有フォルダ・プリンタは別途設定します。

2 台目も同じ手順です。ページ上部で「2 台目」に切り替えるとチェックが別に記憶されます。

!失敗したとき

まず試すこと: ウィンドウはそのままで、同じコマンドをもう一度貼って Enter。これで直ることが多いです（終わった作業は自動で飛ばします）。
赤い文字が大量に出て、その中に「ParserError」「CmdletBinding」「param」が見える: 配布サーバーの古いファイルを掴んでいます。5 分待ってから同じコマンドをもう一度。2 回目も同じなら下の手順で hide さんに送ってください。

赤い枠で 「キッティング途中で失敗」 と出たら、ウィンドウを閉じずに次の手順を。壊れることはありません。
